NovaClient - Fabric, Minecraft 26.3, Java 25

BUILD:   ./gradlew build   (jar-ul apare în build/libs/)
INSTALL: pune jar-ul + Fabric API 0.166.2+26.3 în folderul mods

TASTE (Numpad, schimbabile din Controls):
 1 Ore Finder | 2 Base Finder | 3 Stash Finder
 4 Fullbright | 5 Auto Sprint | 0 Raport (listă în chat)

Alerte automate în chat când găsește stash (8+ containere/chunk)
sau bază (40+ blocuri construite/chunk). Praguri în Finder.java.
